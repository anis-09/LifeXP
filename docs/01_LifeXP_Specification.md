Version: 1.0

# Project Overview

## Project Name

LifeXP

## Tagline

Turn Your Real Life Into A Game

## Vision

LifeXP is a gamified self-improvement platform where users complete real-life missions, earn XP, level up, unlock achievements, maintain streaks, and improve their lives just like playing an RPG game.

The application should feel like a premium mobile game instead of a traditional habit tracker.

# Design Rules

Never use browser alerts.

Never use ugly forms.

Always use premium cards.

Always use rounded buttons.

Always use smooth transitions.

Always include loading states.

Always include empty states.

Always include error states.

---

# Development Rule

Build only the requested module.

Never build future modules automatically.

Wait for the next prompt before implementing another module.

Keep the code clean, modular, scalable and production-ready.
