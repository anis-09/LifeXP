# LifeXP - Game Rules

Version: 1.0

---

# Core Philosophy

LifeXP is NOT a habit tracker.

LifeXP is a Real Life RPG.

Users should feel they are leveling up in real life.

Every completed task should reward the player and make visible progress.

---
